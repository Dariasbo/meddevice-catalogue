Rule 1 - MDR Class III devices are high riskback to ToC or SWRL ToC

If a device has risk class ClassIII, then it is classified as a HighRiskDevice.

->

Rule 2 - IVDR Class D devices are high riskback to ToC or SWRL ToC

->

Rule 3 - Incidents with corrective actionback to ToC or SWRL ToC

->
